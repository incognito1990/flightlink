# FlightLink

Маленькое Android-приложение, которое через кнопку «Поделиться» преобразует
ссылки между **Flightradar24** и **Skycards** и открывает соответствующее
приложение.

Без аккаунтов, сетевых запросов и аналитики — приложение переводит id рейса
между шестнадцатеричной (Flightradar24) и десятичной (Skycards) системами.

**[English version](README.md)**

## Как это работает

Flightradar24 хранит id рейса в шестнадцатеричном виде, Skycards использует тот
же id в десятичном. Например, `0x42693275` — это `1114190453`:

```text
https://fr24.com/SDM6325/42693275        (hex id 42693275)
https://skycards.app/flight/-/1114190453 (decimal id 1114190453)
```

FlightLink распознаёт оба формата и переводит id:

| Исходная ссылка | Результат |
| --- | --- |
| `https://fr24.com/SDM6325/42693275` | `https://skycards.app/flight/-/1114190453` |
| `https://fr24.com/42693275` | `https://skycards.app/flight/-/1114190453` |
| `https://skycards.app/flight/SU95/1114190453` | `https://fr24.com/42693275` |
| `https://skycards.app/flight/-/1114190453` | `https://fr24.com/42693275` |

Необязательный сегмент с типом самолёта отбрасывается — Skycards принимает `-`
вместо типа.

## Установка

Скачайте APK со страницы [Releases](../../releases) и установите. APK собран в
debug-конфигурации; Android попросит разрешить установку из браузера или
файлового менеджера.

Нужен Android 8.0 (API 26) или новее. Для открытия в один тап установите оба
приложения — Flightradar24 и Skycards.

## Использование

1. Откройте рейс в Flightradar24 или Skycards и нажмите **Поделиться**.
2. Выберите **FlightLink** в списке.
3. FlightLink преобразует ссылку и откроет другое приложение.

Можно открыть FlightLink вручную, вставить ссылку и нажать **Конвертировать** →
**Открыть в …**. Если целевое приложение не установлено, откроется его страница
в Play Store. Преобразованную ссылку всегда можно скопировать.

Для ссылок Skycards с параметром `?reg=…` на экране конвертации появляется
кнопка **Открыть страницу самолёта** — дополнительный запасной вариант для
Flightradar24.

## Сборка

### Docker (рекомендуется)

```bash
./scripts/build.sh
```

APK появится в `dist/flightlink-debug.apk`. Скрипт собирает небольшой образ с
JDK 17, Android SDK 34 и Gradle 8.7 и запускает сборку внутри него.

Образ собирается под архитектуру хоста. На ARM64 Dockerfile ставит x86_64
библиотеки и закреплённый `qemu-user` 7.2, а затем запускает через него
x86_64 `aapt2` из Android SDK. Регистрация binfmt_misc не нужна. QEMU
закреплён на 7.2, потому что новые версии ломают разбор аргументов `aapt2`.

### Локальная сборка

На x86_64 нужны JDK 17, Android SDK с platform 34 и build-tools 34.0.0.

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. На ARM64 используйте сборку
в Docker: обычный `./gradlew` потребует такую же обёртку для aapt2.

Юнит-тесты конвертера:

```bash
./gradlew testDebugUnitTest
```

## GitHub Actions

`.github/workflows/build.yml` собирает debug APK на каждый push и pull request,
загружает его артефактом и прикрепляет к GitHub Release при пуше тега вида
`v1.0.0`.

## Структура

```text
app/src/main/java/dev/flightlink/
  LinkConverter.kt   разбор и правила преобразования ссылок
  MainActivity.kt    экран вставки и конвертации
  ShareActivity.kt   невидимая цель для «Поделиться»
  AppLauncher.kt     открытие приложения, браузера или Play Store
```

## Примечания

- Утилита неофициальная и не связана с Flightradar24 AB или Skycards.
- FlightLink не проверяет id рейса на сервере. Если приложение не знает id, оно
  покажет свою страницу ошибки.
- Приложение не запрашивает разрешения и не делает сетевых запросов.
